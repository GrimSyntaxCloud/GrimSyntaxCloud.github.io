## The project

An earlier recipe website prototype containing recipe pages for chili and chicken dishes. JavaScript controls update ingredient amounts for original, half, or double servings.

## The interface

The project combines a recipe index, navigation, ingredient lists, photography, and print controls. Bootstrap provides the layout foundation.

## What this demonstrates

Coordinating content across multiple pages, updating recipe quantities in the DOM, and designing a repeatable recipe layout.

## Current status

This is presented as a source project. Some navigation choices are placeholders, and older visitor-tracking experiments need cleanup before it is suitable for a public demo.
