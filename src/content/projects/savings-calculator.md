## The project

Enter an initial amount, a number of years, and an annual interest rate to calculate a future value with annual compounding.

## The implementation

The script validates the fields, iterates over the requested years, and displays a formatted result. A clear action resets the inputs.

## Scope and limitations

This is an educational programming exercise. It uses a constant annual rate, excludes deposits and withdrawals, and its original currency formatting has edge cases for small values.

## Deployment

All calculations run in the browser. The existing GitHub Pages deployment is linked below the project introduction.
