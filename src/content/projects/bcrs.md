## The project

Bob’s Computer Repair Shop is a web development project built around a computer repair business.

## The stack

The application combines an Angular frontend with an Express backend. Angular Material and PrimeNG provide interface components, while Mongoose connects the server to MongoDB.

The repository also includes Chart.js and Swagger tooling.

## Explore the code

The frontend lives in the `src` directory and the backend lives in `server`. The repository includes build commands and development instructions.
