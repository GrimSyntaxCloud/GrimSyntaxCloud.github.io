## The project

Nodebucket is a task management project with a straightforward workflow: add a task, organize it, and move it to done.

## The interface

The Angular interface has two connected drag-and-drop lists, **Todo** and **Done**. Tasks can be added through a validated form and removed using a delete action.

Angular Material provides the form fields, cards, and controls. Angular CDK handles dragging tasks between the lists.

## Behind the interface

The source separates pages, shared components, data models, and services. A Node.js server includes employee API routes and employee and item models.
