## The project

A task manager developed as a JavaScript learning exercise. Tasks can be added, edited, deleted, sorted, and restored from browser storage.

## The implementation

The repository separates task objects, storage helpers, list behavior, and interface event handlers. The task-list object exposes chainable operations such as load, save, sort, and display.

## What this demonstrates

Object-oriented organization, local persistence, callbacks, and DOM rendering without a framework. Data remains in the browser; this is not a shared or synchronized task service.

## Deployment

GitHub Pages serves the static files. Use sample tasks when exploring this older learning project.
